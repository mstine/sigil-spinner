## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → `generateSigil(statement, planet, options)` | Untrusted statement string; the only attacker-controlled input |
| CLI argv / stdin → library | Second entry point for the same untrusted string; must produce the identical error identity (INT-04) |
| SigilError `.details` → programmatic consumer | Structured struck list echoed back to the caller |

The CLI writes them to stderr, never to a log file or a network sink. Task 1 keeps the payload limited to the struck characters and their reasons; do not add the full raw statement to `.details`, since the existing message already includes it only where Phase 1 chose to. |
| T-02-07 | Denial of Service | `foldStatement` under stacked-combining-mark ("Zalgo") input | low | mitigate | Task 2 adds an explicit fifty-mark stress vector asserting the fold completes and reduces to the single base letter. Verified rather than assumed. |
| T-02-08 | Denial of Service | Regex backtracking in the text layer | medium | mitigate | Every regex in the text layer stays a bare character class with no nested quantifier and no alternation. The README now documents the folding rules but the SVG still embeds statement text only through the escaped `<title>` path.
