<objective>
Stand up the repository and lock the project's canonical data: the seven planetary kameas and the
Pythagorean letter encoder. This is the phase's one-way door — every sigil this tool will ever produce
is determined by these cell values, so they are human-signed-off (D-04) before they are committed, and
their provenance is cited in both code and README (D-01, KAMEA-03).

Purpose: kamea correctness is the highest-cost failure in the project (ROADMAP decision log: "data
correctness is the highest-cost failure and must be locked before anything downstream trusts it").
Every downstream module treats `src/data/kamea.js` as a black-box lookup, so a wrong orientation here
silently produces traditionally-wrong sigils that look fine.

Output: a runnable ESM package skeleton, `src/data/kamea.js` with seven signed-off grids under the
`agrippa` set (D-02), `src/data/pythagorean.js` derived from the cycling formula (CONS-02), exact-value
and Chaldean-rejection test suites, and a README source-lineage section.
</objective>
