<sigil-spinner> element demo

A page-authored, hand-written gallery exercising the <sigil-spinner> custom element: both theming mechanisms side by side, the grid layer revealed, a glyph example, a live attribute-mutation control, and a deliberate error state. No markup on this page is built by string assignment — every <sigil-spinner> below is written literally in the HTML source, and the live control only ever calls setAttribute.

Theming mechanisms

Three instances, same shape, three different styling stories. The unstyled one renders at currentColor — the library's honest, zero-opinion default. The other two prove the two ways a page can theme it, and they are deliberately different in hue and stroke pattern so the difference reads at a glance.

Error state (deliberate)

This instance carries an intentionally invalid planet value, so it never renders a sigil. The dashed red outline is the documented data-sigil-error CSS hook, applied by this page — the library itself ships no default visual for this state.
